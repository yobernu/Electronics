# Dual motor Control System A discrete transistor audio control system built without any ICs.
## Description The system takes a control signal of 0.05 sin(2000pit) and uses it to two motors at differnet direction. - Motor 1 rotates only when the  ratio of inverting amplifer is greater than the ratio of differntial amplifer ,and motor 2 rotates when the current from noninverting amplifer is 2 times the current from voltage controled current source (vccs)
## Components Used - 2N2222 NPN transistors (comparators, AND gates, timers, switches) - 2N2907 PNP transistor (relay driver) - -
